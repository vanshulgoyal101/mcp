mcp.vanshul.com

A public Model Context Protocol server that turns any URL into clean Markdown — so your AI agent can read the live web.

https://mcp.vanshul.com/mcp

Tools

fetch_markdown — fetch a page and return its main article as clean Markdown (nav, ads and boilerplate stripped out). Optional max_chars truncates the result to fit a context budget.
search_page — return only the passages of a page that match a query, each with its heading breadcrumb and ranked by relevance. Finds a detail while spending far fewer tokens than fetching the whole page.
fetch_metadata — return a page's title, byline, site name, excerpt and word count as JSON.
extract_links — return all outbound links on a page (with anchor text) for crawling.

Connect it

Add it to any MCP client that supports remote / Streamable-HTTP servers. For example, in a client config:

{
  "mcpServers": {
    "web-reader": {
      "url": "https://mcp.vanshul.com/mcp"
    }
  }
}

For clients that only speak stdio, bridge with mcp-remote:

npx mcp-remote https://mcp.vanshul.com/mcp

Try it with curl

curl -s https://mcp.vanshul.com/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"fetch_markdown",
                 "arguments":{"url":"https://example.com"}}}'

Notes

  • Extraction is deterministic (Mozilla Readability + Turndown) — no LLM, no data stored.
  • Only public http(s) URLs; private/internal addresses are blocked (SSRF-safe).
  • Requests are rate-limited and page size is capped.

Use cases

  • Give an AI agent live web access — let Claude, Cursor or Continue read the current version of an article or docs page instead of a stale training snapshot.
  • Research & summarisation — pull clean Markdown into a prompt without the nav, ads and cookie banners that waste tokens.
  • Pinpoint a detail — use search_page to return just the passages matching a query (e.g. pricing, a config flag) instead of the whole page.
  • Lightweight crawling — use extract_links to walk a site and follow related pages.
  • Metadata enrichment — grab a page's title, byline and excerpt for citations or link previews.

FAQ

What is the MCP Web Reader server?
A free, public Model Context Protocol server that fetches any web page and returns its main content as clean Markdown, plus metadata and outbound links, over the Streamable HTTP transport.

Which MCP clients can connect?
Any client that supports remote / Streamable-HTTP MCP servers — Claude Desktop, Cursor, Continue and more. Point it at https://mcp.vanshul.com/mcp, or bridge stdio-only clients with npx mcp-remote.

Does it need an API key or store my data?
No key, and no page content is stored. Extraction is deterministic (Mozilla Readability + Turndown) with no LLM in the loop.

Is it safe against SSRF?
Yes — only public http(s) URLs are allowed; localhost, private ranges and cloud metadata are blocked and every redirect hop is re-validated. Requests are rate-limited and page size is capped.

What tools does it expose?
fetch_markdown (with an optional max_chars budget), search_page (relevance-ranked passages matching a query), fetch_metadata and extract_links.
